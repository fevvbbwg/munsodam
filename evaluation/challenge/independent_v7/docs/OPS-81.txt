# FIELDNOTE 장비·물류 운영 지침

## 교정 장비 사용
센서와 측정 장비를 사용하려면 사용일 기준 2근무일 전까지 BenchTrack에 교정 요청을 등록한다. 교정 완료 표시는 장비 라벨의 초록색 점검일 스티커로 확인한다. 측정 콘솔은 입력이 8분 동안 없으면 자동 잠금되며, 다시 사용하려면 사원 배지를 태그한다. 장비 점검 기록은 별도 보관 기한을 정하지 않았다.

## 저온 배송 인수
저온 배송을 인수하면 상자 온도와 봉인 상태를 확인해 ColdLedger에 기록한다. 온도 기록은 인수 시점부터 36시간 동안 보관한다. 상자 봉인이 훼손되었거나 온도가 6°C를 초과하면 인수를 완료 처리하지 말고 품질 담당자에게 즉시 알린다. 일반 박스의 폐기 비용은 이 지침에 정하지 않았다.
